# Cargo Dimension and Weight Classification Skill

Evaluates cargo physical properties to determine freight rating parameters.

## Core Capabilities
- Calculates cubic volume and dimensional weight using standard divisors.
- Determines whether shipments require LTL, Partial Truckload, or Full Truckload (FTL).
- Checks regulatory axle load limits and flags overweight permit requirements.
